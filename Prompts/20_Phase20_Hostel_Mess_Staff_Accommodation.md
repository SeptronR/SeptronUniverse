# PHASE 20 — HOSTEL, MESS & STAFF ACCOMMODATION

## Pre-Requisite
Phases 01–12 complete (students/guardians with OTP-capable phones, staff, holds, fee linkage incl. caution deposits and refunds, no-dues clearance, workflow engine, SMS channel, holidays). Phase 25 (`service_requests`) is optional — hostel complaints link to service-desk tickets when `facilities.service_desk` is enabled, otherwise they are tracked locally.

## Objective
Residential life end-to-end: hostels → blocks → rooms → beds with fee plans per room type and year; applications with priority scoring and preference-based **allotment runs** (waitlists); allocations with hostel fee + caution deposit invoices, check-in with room-condition record, room-change requests, transfers, vacate with damages, no-dues and caution-deposit refund, eviction; **night roll-call** with guardian alerts; **mess** (plans/diets/menus, subscriptions, meal attendance by QR/RFID/manual, rebates, monthly bills); visitors register; **out-pass & leave** with guardian OTP consent, warden approval workflow, **gate QR** mark-out/return, late-return and absconding handling; complaints; hostel discipline with fines; **staff quarters** with rent deduction to payroll — each with **My hostel** (student/parent) vs warden (own hostels) vs admin (all) views.

## Feature keys
`hostel.core`, `hostel.mess`, `hostel.mess_billing` (depends `fees.core`), `hostel.leave_outpass` (depends `comms.sms`), `hostel.gate_qr` (depends `mobile.app`), `hostel.night_roll_call`, `hostel.room_change`, `hostel.visitors`, `hostel.complaints` (depends `facilities.service_desk`), `hostel.discipline`, `hostel.staff_quarters` (depends `hr.staff`) — all off by default, standard tier; `portals.warden` (off, standard).

## 20.6 Services
- `structure_service.py`: hostels (type, warden, capacity derived = Σ beds), blocks, rooms bulk generation (`number_pattern` e.g. `{floor}{seq:02}`), beds auto-created per `capacity` (labels A/B/C), room status (`maintenance|blocked` frees no beds but hides them from allotment), fee plans per room type × year; occupancy map (blocks → rooms → beds with resident chips).
- `application_service.py`
  1. Apply within window (`institution_settings['hostel.application_window']` per year); one per enrolment per year (UNIQUE); `hostel_preference[]` ordered; `priority_score` = weights from settings: distance band (e.g. > 100 km = 40), category (SC/ST/EWS bonus), CGPA/merit (admission rank for first years), sports/NCC quota, sibling in hostel, PwD (top priority); female students only to `girls|coed` hostels etc. by `hostel_type` vs gender; blocked when `student_holds(hostel|all)` or `hostel_disciplinary_records.action='eviction'` in the past 2 years.
  2. `allotment_run(scope, year, dry_run)` (job): iterate applications by `priority_score DESC, applied_at`, walk preferences → first hostel with a vacant bed of `room_type_pref` (fallback to any room type when setting) → `hostel_allocations(status='allotted')` with `FOR UPDATE SKIP LOCKED` on beds; remaining → `waitlisted` with position; `dry_run` returns the summary without writes; emits `hostel.allotted/waitlisted`; waitlist promotion when a bed frees (Beat or on vacate) in score order.
  3. Manual allot/decline; student accepts by paying (allotment lapses after `accept_days` → bed released, next waitlisted promoted).
- `allocation_service.py`
  1. On allotment: invoices via `fee_service.create_invoice(payer=student, source_type='hostel_allocation', source_id=allocation, items=[hostel fee per term from plan])` and a separate caution-deposit invoice (`fee_head=caution_deposit`, refundable) unless a deposit is already held (setting `deposit_once`); mess advance optional.
  2. `check_in` (warden): requires hostel fee paid or instalment plan active (setting), records `room_condition` + inventory, `check_in_at`, bed `allocated`, room `full` when all beds allocated; generates allotment letter (template); emits `hostel.checked_in` (Phase 07 student profile shows hostel).
  3. `transfer(new_bed)`: within/between hostels; old allocation → `transferred`, new row `checked_in` in one transaction; fee difference invoice/credit when room type changes.
  4. Room change requests (`hostel.room_change`): student → workflow `hostel.room_change` (warden) → `applied` executes transfer.
  5. `vacate(request)`: `room_condition` compare → damages → fine invoice (`source_type='hostel_disciplinary'`? no — `hostel_allocation` with item `Damages`), `check_out_at`, allocation `vacated`, bed `vacant`; auto-create `no_dues_requests(purpose='hostel_vacate')` (Phase 12) with hostel + mess steps; when cleared and no outstanding hostel/mess invoices → caution deposit refund request (`fee_refunds` with `source=caution_deposit`, netting damages/dues) → accountant processes; emits `hostel.vacated`; end-of-year bulk vacate job with reminders.
  6. `evict(reason)` (warden proposes → registrar approves via `hostel.eviction` workflow): allocation `evicted`, bed freed, disciplinary record `eviction`, hold `hostel` placed for the configured period.
- `roll_call_service.py` (`hostel.night_roll_call`): one roll-call per hostel per night (UNIQUE); entries pre-filled `on_leave` for residents with an approved/out leave covering the time, otherwise warden marks present/absent (bulk, mobile grid, offline queue); unmarked after `roll_call_time + 60 min` → `absent` by Beat; absent without leave → guardian + warden notification, 3 absences in 30 days → discipline warning auto; reports per hostel/date.
- `mess_service.py` (`hostel.mess`, `hostel.mess_billing`)
  1. Plans per hostel (or shared) with diet and weekly `menu` JSONB; subscriptions (one active per enrolment; change effective next month) with invoice when billing is prepaid (`source_type='mess_subscription'`).
  2. Attendance per meal by QR (student ID QR / mess card), RFID device push, or manual; duplicates ignored (UNIQUE); guests meals as wallet debits when `facilities.canteen_wallet` on.
  3. Rebates: student requests `from/to` (≥ `rebate_min_consecutive_days`, tied to an approved hostel leave when `rebate_requires_leave`) → warden approves → `mess_attendance.status='rebate'` rows.
  4. Monthly bill job: `days_billed = days in month − rebate_days − closure days (holidays with mess closed)`; `amount = monthly_fee × days_billed / days_in_month` (or per-day rate) → `mess_bills` + invoice `source_type='mess_subscription'` (postpaid) or adjustment against advance (prepaid); notification; unpaid bills → dues for no-dues.
- `visitor_service.py` (`hostel.visitors`): log in/out with ID proof (masked in lists), allowed hours from hostel rules, guardian-only rule for girls hostels when set, monthly register export.
- `leave_service.py` (`hostel.leave_outpass`, `hostel.gate_qr`)
  1. `create`: types with max duration per type (out_pass ≤ 1 day, day_leave, home_leave, medical); overlapping active leave → 409; exam-day rule (block out-pass during exam sessions unless medical, from Phase 14 date-sheet when available); `guardian_consent` = `pending` when type ∈ `guardian_otp_required_for` or student is minor (`dob`) → OTP to primary guardian phone (`comms.sms`) with 6-digit code, 3 attempts, 10 min validity; parent app "Approve" button = verified consent alternative; `not_required` otherwise.
  2. Approval: workflow `hostel.leave` (warden of the hostel; auto-approve rule for `out_pass` within hours when setting); cannot approve while consent `pending`; approved → `qr_token` (signed, valid `from_at−1h … to_at+grace`) + notification.
  3. Gate scan (`hostel:gate`, mobile QR): `direction=out` → `status='out'`, `actual_out_at`; `direction=in` → `returned` or `late_return` when `actual_return_at > to_at + late_grace_minutes` with `late_minutes`; late → fine per `fine_configurations(hostel)` (optional) + disciplinary note auto (`warning` first, `fine` on repeat) + guardian notification `hostel.late_return`; scanning an expired/unknown QR → 404/409 with reason shown to gate staff; offline scans queued with device time and reconciled server-side (server wins on conflicts).
  4. `absconding`: Beat marks `out` leaves not returned `absconding_after_hours` past `to_at` → `absconding`, escalations to warden, registrar and guardian; return later → `late_return` with audit trail.
  5. Cancel by student before `out`; warden override to mark returned manually with remarks (audited).
- `complaint_service.py` (`hostel.complaints`): categories (electrical/plumbing/cleaning/wifi/food/other), warden triage; when `facilities.service_desk` on → create `service_requests` and mirror status by events; else local status machine; ratings on resolution.
- `discipline_service.py` (`hostel.discipline`): records with action; `fine` → invoice (`source_type='hostel_disciplinary'`); `suspension` (dates; hostel access blocked; roll-call entries `on_leave`); `eviction` via workflow; guardian notified; counts feed Phase 27 discipline register (event `hostel.discipline_recorded`).
- `quarters_service.py` (`hostel.staff_quarters`): quarters master (type, rent), allocation (one active per quarter), `rent_deduction=true` → emits `payroll.deduction_requested` consumed by Phase 06 payroll to add a `staff_payroll_items(component_type='deduction', source_type='staff_quarter')` line monthly; vacate closes deduction; waiting list optional.
- `no_dues_hook`: `@engine.on("no_dues.clearance", step="hostel")` auto-clears when no active allocation (or allocation vacated with damages settled), no unpaid hostel/mess invoices; else `dues_pending`.
