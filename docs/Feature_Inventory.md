# SeptronUniverse — Feature Inventory (per phase, per institution type)

Legend — **Type**: R reuse Orbit design with renames · R+ reuse and extend · N new for higher-ed. **Applicability**: ✓ standard · ○ optional (feature flag off by default) · — not applicable. Institution types: **AFF** affiliated college · **AUT** autonomous college · **UNI** university (with affiliated/constituent colleges) · **MC** multi-campus institution.
