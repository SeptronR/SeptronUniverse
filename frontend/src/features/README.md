# features/<module>

One folder per business module (`api.ts`, `hooks.ts`, `types.ts`, `pages/`, `components/`) — generated by
`python backend/scripts/scaffold_module.py <module> --feature <key> --permissions <module>`.

Rules (Prompts/00 §7 Frontend): API calls only in `api.ts` (typed from `@/api/generated/openapi`), hooks wrap TanStack
Query with keys `[module, params]`, every list uses `DataTable` + `ScopeTabs` when `meta.visibility.scopes.length > 0`,
every form is RHF + Zod, every async result toasts, every fetch shows a skeleton.
